## Como executar

1. Use uma instalação local de MySQL e um cliente SQL, como o MySQL Workbench.
2. Abra um dos arquivos `.sql`.
3. Leia o script e execute os trechos na ordem: criação do banco, tabelas, dados e consultas.

Alguns scripts começam com `DROP DATABASE`, que apaga o banco indicado. Use uma base de estudo e confira o nome antes de executar. Em arquivos com `DROP DATABASE` sem `IF EXISTS`, a instrução pode falhar quando o banco ainda não existe; nesse caso, comece pela criação do banco.
